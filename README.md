# Kampüs Etkinlik Takip Sistemi — Frontend

## Kısa Açıklama

Bu proje, kampüs etkinliklerini listeleyen, etkinlik detaylarını gösteren ve kullanıcı profili/auth akışı sağlayan React tabanlı bir frontend uygulamasıdır. Amaç, üniversite içindeki etkinliklerin keşfedilmesini ve yönetilmesini kolaylaştırmaktır.

Öne Çıkan Özellikler

- Etkinlik listesi ve detay sayfaları
- Kullanıcı kayıt / giriş / profil sayfası
- Etkinliklere katılım / takip akışları (backend gerekli)
- Basit ve duyarlı tasarım

Teknoloji Yığını

- React 19
- Vite
- react-router-dom
- axios
- ESLint

## Dokümantasyon

- ADIM V (Bileşenler ve arayüzler): [../../docs/adim-v-bilesenler.md](../../docs/adim-v-bilesenler.md)

Önkoşullar

- Node.js >= 18
- npm (veya tercih ederseniz `yarn` / `pnpm`)

## Kurulum & Çalıştırma

1. Depoyu klonlayın:

```bash
git clone https://github.com/Zehranur04/kampus-etkinlik-takip-sistemi-web.git
cd kampus-etkinlik-takip-sistemi-web
```

2. Paketleri yükleyin:

```bash
npm install
```

3. Geliştirme sunucusunu başlatın:

```bash
npm run dev
```
